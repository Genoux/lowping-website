## Project Overview

Lowping is a Next.js platform for esports tournament management. Players can browse tournaments, register for events, and complete a simulated checkout process.

## Features

### Tournament Management
- Browse upcoming and past tournaments
- Filter events by status
- Individual tournament pages with event details

### Registration System
- Form-based registration
- Simulated payment processing
- Confirmation pages with event details

### Technical Implementation
- Next.js 15 with App Router
- Tailwind CSS
- Framer Motion animations
- TanStack Query
- TypeScript
- Responsive design with mobile navigation

## Demo Flow

1. Browse tournaments
2. Register for an event
3. Complete simulated checkout
4. View confirmation page
